# t003 — Add a click counter button

**State:** Not started
**Depends on:** t002

## Goal

A "Click me" button that counts clicks and shows the count, e.g. "Clicked 3 times".

## Scope

- A "Click me" button and a count text in `index.html`.
- `app.js` (new): connects the button to `addOne` and shows the text.
- A new function `clickText(count)` in `logic.js` that makes the text.
- Tests for `clickText` in `tests/logic.test.js`.
- Small styles for the button in `styles.css`.

## Out of scope

- A reset button (t004).
- Keeping the count after the page is closed.

## Acceptance criteria

- [ ] When the page opens, it shows "Clicked 0 times".
- [ ] Each click on "Click me" adds one: "Clicked 1 time", "Clicked 2 times", …
- [ ] It says "1 time", not "1 times".
- [ ] `clickText` doesn't break on a bad value (like `-1` or `"hi"`): it shows "Clicked 0 times".
- [ ] `npm test` covers 0, 1, many and a bad value.

## How to verify

1. `npm test` → all tests pass.
2. Double-click `index.html` → click the button a few times → the text counts correctly.

## Evidence

Filled in by the PR that finishes this task: what was checked, the result (passed / failed /
not run) and the PR link.
