# t008-05 — Add agent role skills

**State:** Not started
**Kind:** Leaf
**Parent:** [t008](t008.md)
**Depends on:** t008-04

## Goal

Each agent role in the delivery loop has its own written instructions, so a fresh agent session
can do one role well without being told everything again.

## Scope (draft)

- `.claude/skills/` with one skill per role: delivery supervisor, task readiness, implementation
  worker, PR-readiness review, design review.
- Each skill says when it is used, what it reads, what it may and may not do, and what it reports.
- `AGENTS.md`: lists the skills and when to use each one.

## Out of scope

- Changing the delivery loop itself (t008-04).

## Acceptance criteria

Written at the readiness step, before any work starts.

## Evidence

Filled in by the PR that finishes this task.

---

## 🎓 Learning purpose

**Who drives:** Claude writes. Matan types the commands and reviews.

**What Matan learns:** how work is split between agent roles (one agent builds, another one
reviews), and how a skill gives each role its instructions.
