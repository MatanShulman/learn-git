**State:** Not started

## Goal

Each kind of information has one clear home: how to set up and check the project, what the
product is, and how the code is built. `README.md` points to all of them.

## Scope (draft)

- `docs/development.md`: how to set up the project, run the checks and check main health.
- A product design doc: what Tiny Page shows and does.
- `docs/software_design/architecture.md`: the app's files and how they connect (`index.html`,
  `logic.js`, `app.js`, the tests).
- `README.md`: the project status and an index of all docs.

- The agent skills (t008-05).
