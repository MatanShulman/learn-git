# t001 — Add the main page

**State:** Not started
**Depends on:** nothing

## Goal

A main page that opens by double-clicking `index.html` and shows the title "Tiny Page" and the
subtitle "A tiny page."

## Scope

- `index.html` with the title and the subtitle.
- `styles.css` with basic styles (font, spacing, centered content).
- `README.md`: how to open the page.

## Out of scope

- Buttons and JavaScript (t003).
- Tests and CI (t002).

## Acceptance criteria

- [ ] Double-clicking `index.html` shows the title "Tiny Page" and the subtitle "A tiny page."
- [ ] The browser tab shows "Tiny Page".
- [ ] The page uses the styles from `styles.css` (not the browser's plain look).
- [ ] It doesn't break on a narrow, phone-sized window (no sideways scrolling).

## How to verify

1. Double-click `index.html`.
2. Press F12 → click the phone icon (device toolbar) → pick a phone size. The page must still fit.

## Evidence

Filled in by the PR that finishes this task: what was checked, the result (passed / failed /
not run) and the PR link.
