# t008-02 — Set the backlog conventions

**State:** Not started
**Kind:** Leaf
**Parent:** [t008](t008.md)
**Depends on:** t008-01

## Goal

Every task file uses the same fields, states and evidence format, so anyone (a person or an agent)
can read a task's status, its place in the plan and its history the same way.

## Scope (draft)

- `docs/backlog/index.md`: the rules for task ids (stable, never renumbered or reused), parent and
  child tasks (`t008`, `t008-01`), and the fields every task file has (State, Kind, Parent,
  Depends on, and others chosen at readiness, such as Priority).
- States: `Not started` / `In progress` / `Blocked` / `Done`. `AGENTS.md` rule 13 matches them.
- Evidence: dated, with the exact commit (SHA) it was checked on.
- A short review checklist for task files.
- Convert t001–t007 and t008 with its children to the new format.

## Out of scope

- Changing what any task asks for: goals and acceptance criteria stay the same.
- Stages and gates (a later task).

## Acceptance criteria

Written at the readiness step, before any work starts.

## Evidence

Filled in by the PR that finishes this task.
