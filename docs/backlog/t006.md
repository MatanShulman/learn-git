# t006 — Improve the page style

**State:** Not started
**Depends on:** t005

## Goal

Make the page look nicer with one small style change. The exact change (for example colors, font
or button shape) is written here before work starts.

## Scope

- `styles.css` (and `index.html` only if the change needs it).

## Out of scope

- Any change to how the buttons work.

## Acceptance criteria

- [ ] (1–2 criteria for the chosen change, written before any code.)
- [ ] The page doesn't break on a narrow, phone-sized window.
- [ ] Both buttons still work, and `npm test` passes.

## How to verify

1. `npm test` → all tests pass.
2. Double-click `index.html` → check the change, click both buttons.
3. F12 → phone icon → the page still fits.

## Evidence

Filled in by the PR that finishes this task: what was checked, the result (passed / failed /
not run) and the PR link.
