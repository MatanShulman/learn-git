# t004 — Add a reset button and rename the counter button

**State:** Not started
**Depends on:** t003

## Goal

A "Reset" button that sets the counter back to 0, and a clearer text on the counting button:
"Add one" instead of "Click me".

## Scope

- A "Reset" button in `index.html`, handled in `app.js`.
- The counting button's text changes from "Click me" to "Add one".
- A small style for the reset button in `styles.css`.

## Out of scope

- Keeping the count after the page is closed.
- Any other text or style changes.

## Acceptance criteria

- [ ] Clicking "Reset" shows "Clicked 0 times".
- [ ] After a reset, "Add one" counts from 1 again.
- [ ] Clicking "Reset" when the count is already 0 changes nothing and doesn't break.
- [ ] The counting button says "Add one".
- [ ] `npm test` still passes.

## How to verify

1. `npm test` → all tests pass.
2. Double-click `index.html` → click "Add one" 3 times → "Reset" → "Add one" → shows
   "Clicked 1 time".
3. Click "Reset" twice in a row → still "Clicked 0 times", no errors in F12 → Console.
