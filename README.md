# Tiny Page

A tiny web page with a title, a subtitle and a click counter, made with plain HTML, CSS and
JavaScript (no framework, no build step).

This repo is used to practise a team workflow on GitHub: every change goes through a task file,
a branch, a pull request, automatic checks and a review before it reaches `main`.
